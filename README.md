# AdventureWorks Sales Data Analysis

## Project Overview
Analyzed AdventureWorks sales data using Python to identify revenue trends, evaluate product performance, and understand customer purchasing patterns. Used data cleaning, transformation, aggregation, and visualization techniques to derive meaningful business insights.

## Tools and Technologies
- **Programming Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib
- **Dataset Format:** CSV
- **Version Control:** Git and GitHub

## Dataset
The project uses four datasets covering:
- Customers
- Products
- Sales transactions (2017)
- Sales territories

The datasets are provided in `AdventureWorks_Datasets.zip`.

## Key Analysis
- Monthly revenue trends
- Total revenue by country
- Top 5 products by gross profit
- Revenue breakdown by customer age group

## How to Run the Project

1. Download or clone this repository.
2. Extract `AdventureWorks_Datasets.zip` into the project folder.
3. Install the required libraries:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the Python script:

   ```bash
   python data.py
   ```

**Note:** Ensure the extracted CSV filenames and file paths match those used in `data.py`.

Python programming, data cleaning, data manipulation, exploratory data analysis (EDA), data aggregation, and data visualization.
